Before You Begin 2 min read

What You Need to Know First

The Terminal

Throughout this guide you will use an app called Terminal. Open it by pressing ⌘ Space, typing Terminal, and pressing Enter. It is a text-based way to talk to your Mac and far more powerful than clicking around. Do not worry; we will tell you exactly what to type every step of the way.

🖼️Screenshot coming soon: images/terminal-app.png
What the Terminal app looks like once it's open
Prerequisites

Make sure your Mac is plugged in and has at least 10 GB of free space. Check under Apple menu → About This Mac → More Info → Storage. Also make sure macOS is up to date, with Ventura 13 or Sonoma 14 being ideal.

Good to know

When you paste a command into Terminal and press Enter, it might look like nothing is happening. That is normal; some commands just take time. When it finishes, you will see the $ prompt reappear. Also, when typing your Mac password in Terminal, no characters will appear on screen. That is a security feature, so just keep typing and press Enter.

Step 1 ~3 min

Homebrew

What is this?

Homebrew is a package manager, basically an app store for your Terminal. Instead of hunting down installers from websites, you type one command and Homebrew installs the software for you automatically.

Why do I need it?

You will use Homebrew to install Git, Python, Java, and almost everything else in this guide. It is the single most useful tool on a developer's Mac, used by professionals worldwide. As a bonus, Homebrew also installs the required macOS developer tools automatically if they are not already on your machine. In your intro CS courses, whenever a professor says "just install X," Homebrew is usually the fastest way to get it running.

Apple Silicon (M1 / M2 / M3) users, check this first

Check Apple menu → About This Mac. If you see an Apple M-series chip listed, Homebrew will install to /opt/homebrew instead of the usual path. Keep this in mind for Step 3 below; you will need to follow the PATH instructions that Homebrew prints after the install completes.

What does this command actually do?

It downloads Homebrew's official install script from GitHub and runs it. That script asks for your admin password because it needs permission to create folders on your Mac that Homebrew will manage. If you would rather read the script before running it, the source is publicly viewable at the URL inside the command. This is the standard, official way to install Homebrew and is the same command listed on brew.sh.

  1. Paste this into Terminal and press Enter. It is one long command, so use the Copy button to grab all of it at once.
    Terminal
    $ /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
  2. Enter your Mac password when asked. Characters will not appear as you type; just type your password and press Enter.
  3. If you see a message about adding Homebrew to your PATH, copy and run the two commands it shows you. They look like echo '...' and eval "$(...". This step is important and should not be skipped. (This is the Apple Silicon PATH step mentioned above.)

Step 2 ~2 min

Git

What is this?

Git is a version control system that keeps track of every change you make to your code. Think of it as an undo history on steroids where you can go back to any previous version, work on multiple features at once, and collaborate with teammates without overwriting each other's work.

Why do I need it?

Every CS course will eventually expect you to know Git. It is also considered a basic skill by every employer in tech, and you will use it to submit assignments and collaborate on group projects. Expect to see it in almost every programming class after your first semester, especially group projects.

  1. Install Git via Homebrew:
    Terminal
    $ brew install git
  2. Set your name so it appears on your commits. Use your real name.
    Terminal
    $ git config --global user.name "Your Full Name"
  3. Set your email. Use the same email you will use for GitHub.
    Terminal
    $ git config --global user.email "you@example.com"
✓ Verify it worked
Terminal
$ git --version
Expected: git version 2.x.x
A quick preview of how Git is actually used

This step only installs and configures Git; it does not teach you the daily workflow. Once you have a project folder, the basic loop looks like this (nothing to run yet, just for reference):

Example
$ git add .
$ git commit -m "describe what you changed"
$ git push

Git is deep enough to deserve its own guide. For a proper walkthrough, see Git Basics from the official Git book or GitHub's own Using Git guide.

Step 3 ~5 min

GitHub Account

What is this?

GitHub is a website that stores your Git code repositories in the cloud, similar to Google Drive but built specifically for code. It is what essentially every software team in the world uses to collaborate.

Why do I need it?

Professors often require GitHub for assignment submissions. It is also your public coding portfolio, and future employers and internship programs will look at it. Many CS courses have you submit homework by pushing to a class GitHub repository, so this account is not optional for long.

  1. Create a free account at github.com if you do not already have one. Use your university email address.
  2. Install the GitHub CLI so you can connect your Mac to GitHub directly from the Terminal:
    Terminal
    $ brew install gh
  3. Log in to GitHub from Terminal:
    Terminal
    $ gh auth login
    When prompted, choose GitHub.com, then HTTPS, then authenticate via browser. A browser tab will open; click Authorize.
What is this command actually doing?

gh auth login never asks for or sees your GitHub password. It opens your browser and lets GitHub itself generate a secure, revocable access token that only your Terminal uses. You can review or revoke that access anytime under your GitHub account's Settings → Applications.

✓ Verify it worked
Terminal
$ gh auth status
Expected: ✓ Logged in to github.com as YourUsername
🖊️
Step 4 ~5 min

Visual Studio Code

What is this?

VS Code is a free, powerful code editor made by Microsoft. It is the most popular editor in the world and natively supports Python, Java, C++, and essentially every language you will encounter in your CS program.

Why do I need it?

A proper editor makes coding dramatically easier, with syntax highlighting, autocomplete, error detection, a built-in Terminal, and Git integration all in one place. This is likely the editor you will use in nearly every programming assignment across your degree, regardless of which language a course focuses on.

  1. Install VS Code via Homebrew:
    Terminal
    $ brew install --cask visual-studio-code
  2. Open VS Code from your Applications folder or by pressing ⌘ Space and typing VS Code.
  3. Enable the code command. Inside VS Code, press ⌘ Shift P, type Shell Command, and select "Install 'code' command in PATH". After this you can type code . in Terminal to open any folder instantly in VS Code.
  4. Install these essential extensions. Click the Extensions icon (four squares on the left sidebar), search for each name, and click Install:
    • Python by Microsoft — run and debug Python files
    • Extension Pack for Java by Microsoft — full Java support
    • C/C++ by Microsoft — C and C++ highlighting and debugging
    🖼️Screenshot coming soon: images/vscode-extensions.png
    The Extensions panel with all four extensions installed
✓ Verify it worked

Open Terminal and run:

Terminal
$ code --version
Expected: 1.xx.x (any version number)

Step 5 ~2 min

Python 3

What is this?

Python is a beginner-friendly programming language that reads almost like plain English. It is the most popular first language in CS programs worldwide and is widely used in AI, data science, web development, and scripting.

Why do I need it?

Most intro-to-programming courses (often labeled CS 101 or similar) are taught in Python because its simple syntax lets you focus on logic instead of fighting the language. You will likely write your very first "real" program in Python.

Does my Mac already have Python?

Macs come with Python 2 (very old and no longer supported) or a non-functional stub. We are installing Python 3, the current version. On your Mac, always use python3 rather than python.

  1. Install Python 3 via Homebrew:
    Terminal
    $ brew install python3
✓ Verify it worked
Terminal
$ python3 --version
Expected: Python 3.12.x (3.10 or higher is fine)

Try running a quick test to confirm everything works:

Terminal
$ python3 -c "print('Hello, CS!')"
Expected: Hello, CS!

Step 6 ~3 min

Java (OpenJDK)

What is this?

Java is a foundational programming language heavily used in CS courses for data structures, algorithms, and object-oriented programming. The JDK (Java Development Kit) is what lets you write and run Java programs on your Mac.

  1. Install OpenJDK, the free and open-source version of Java:
    Terminal
    $ brew install openjdk
  2. Add Java to your PATH so Terminal can find it. Run both commands:
    Terminal
    $ echo 'export PATH="/opt/homebrew/opt/openjdk/bin:$PATH"' >> ~/.zshrc
$ source ~/.zshrc
    If you have an Intel Mac rather than an M-series Mac, replace /opt/homebrew with /usr/local.
✓ Verify it worked
Terminal
$ java --version
Expected: openjdk 21.x.x (any version is fine)
⚡
Step 7 ~1 min

C++

What is this?

C++ is a powerful, fast language used in systems programming, game development, and performance-critical software. It is commonly used in CS courses to teach memory management, pointers, and low-level concepts.

Good news!

When you installed Homebrew in Step 1, it automatically set up the macOS developer tools your Mac needs, including the C++ compiler clang++. There is nothing extra to download.

  1. Verify your compiler is available:
    Terminal
    $ clang++ --version
  2. Create an alias so g++ also works, since some professors and textbooks use that name:
    Terminal
    $ echo 'alias g++="clang++"' >> ~/.zshrc && source ~/.zshrc
  3. Test it by compiling a real C++ program:
    Terminal
    $ echo '#include <iostream>
int main(){std::cout<<"Hello, C++!"<<std::endl;}' > test.cpp
$ clang++ test.cpp -o test && ./test
✓ Verify it worked
Expected output: Hello, C++!

Clean up the test files when you are done:

Terminal
$ rm test.cpp test
✨
Bonus Step ~3 min Optional

Oh My Zsh

What is this?

Oh My Zsh upgrades your Terminal experience with colors, autocomplete suggestions, Git branch names in your prompt, and other quality-of-life improvements. It is not required to write code, but most CS students install it eventually and wonder how they lived without it.

  1. Install Oh My Zsh:
    Terminal
    $ sh -c "$(curl -fsSL https://raw.githubusercontent.com/ohmyzsh/ohmyzsh/master/tools/install.sh)"
  2. When asked if you want to change your default shell, type Y and press Enter.
  3. Close Terminal and reopen it. Your new colorful prompt will appear.
✓ Verify it worked
Your Terminal prompt should now show something like: ➜ ~
